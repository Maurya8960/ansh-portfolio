# 🚀 Ansh Maurya - AI-Powered Portfolio

A modern portfolio website with an integrated RAG chatbot that answers recruiter questions about my background.

## ✨ Features

- 💬 AI Chatbot - RAG-powered assistant
- 🎯 Source Citations - Every answer shows its source
- 🎨 Modern UI - Glassmorphism, animations, dark/light mode
- 📱 Fully Responsive - Works on all devices

## 🛠️ Tech Stack

- Frontend: Next.js 14, React 18, Tailwind CSS
- AI/ML: Google Gemini API
- Architecture: RAG with keyword-based retrieval
- Deployment: Vercel
